# Java Practice Repository ☕

This repository is used for learning and practicing Java.

The goal is to improve problem-solving skills, understand core Java concepts, and build solutions without relying on IDE assistance.

All code is written in **Sublime Text** to avoid IDE auto-completion and suggestions, making the learning process more intentional and helping reinforce Java fundamentals.

## Run the code

Compile:

```bash
javac Main.java
```

Run:

```bash
java Main
```

## Purpose

This repository contains various Java exercises, algorithms, data structures, and coding challenges.  
It will continue to grow over time as new topics and problems are added.
